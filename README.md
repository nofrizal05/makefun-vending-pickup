One pickup line, 200 characters at most, that a vending machine would use on a passing human — spoken by the machine itself, from its own world of buttons, coils, snacks, hum, and exact change. Written for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty.

## Run it

```sh
python3 main.py
```

This writes exactly one line to `/output/entry.txt`.
